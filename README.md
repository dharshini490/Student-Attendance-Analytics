
# Student Attendance Analytics

## Project Description
A Python-based student attendance analytics dashboard developed using Streamlit.

## Features
- Student attendance calculation
- Attendance percentage analysis
- Present and absent statistics
- Identification of students below 75%
- Interactive attendance chart
- Downloadable attendance report

## Technologies Used
- Python
- Pandas
- Streamlit
- Plotly

## How to Run
1. Install the required libraries:
   pip install -r requirements.txt

2. Run the application:
   streamlit run app.py
